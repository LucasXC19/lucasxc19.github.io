# Matemática e Jogos

Este projeto contém dois jogos educativos que ajudam a aprender matemática de forma divertida.

## Estrutura do Projeto

- **src/index.md**: Este arquivo contém a estrutura básica do projeto, incluindo links para os jogos "Campo Minado" e "Jogo da Memória Com Algarismos Romanos".
  
- **src/CampoMinado/CampoMinado.html**: Implementação do jogo "Campo Minado". Este arquivo contém o código HTML necessário para a interface do jogo.

- **src/JogoDaMemoria/JogoDaMemoria.html**: Implementação do jogo "Jogo da Memória Com Algarismos Romanos". Este arquivo contém o código HTML necessário para a interface do jogo.

## Instruções de Instalação

1. Clone o repositório para sua máquina local.
2. Navegue até a pasta do projeto.
3. Abra o arquivo `src/index.md` em um navegador para acessar os jogos.

## Como Jogar

- **Campo Minado**: O objetivo do jogo é descobrir todas as células sem ativar as minas. Use a lógica e a matemática para deduzir onde as minas estão localizadas.

- **Jogo da Memória Com Algarismos Romanos**: Este jogo desafia os jogadores a encontrar pares de cartas com algarismos romanos. É uma ótima maneira de praticar a memorização e o reconhecimento de números romanos.
